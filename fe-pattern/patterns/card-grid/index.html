Card Grid

A responsive grid of feature cards that reflows from many columns on desktop to a single column on mobile. Uses CSS grid with auto-fill + minmax().

⚡

Fast by default

Zero build step and no runtime bundle. The page ships as plain HTML, CSS, and JS.

🔒

Accessible

Semantic landmarks, focus states, and ARIA roles work without a library.

🎨

Themed

Light and dark both come from CSS custom properties — switch the theme in one place.

📱

Responsive

The grid reflows automatically as the viewport narrows, no media queries required.

🧩

Composable

Add or remove cards by editing the HTML. Layout stays consistent either way.

🔧

Customizable

Tune spacing, radius, and accent color through the variables on :root.
