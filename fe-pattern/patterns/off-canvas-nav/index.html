Off-canvas navigation

Hamburger + overlay on mobile; persistent drawer on desktop. Focus trap, ESC to close, focus restoration.

Open the menu with the hamburger button (mobile) or by focusing the toggle and pressing Enter/Space. While the mobile menu is open, Tab stays trapped inside it, Escape closes it, and focus returns to the toggle.

On a wide screen the drawer is always visible and the page content flows beside it — no overlay, no toggle. Resize the window to see the layout adapt.
