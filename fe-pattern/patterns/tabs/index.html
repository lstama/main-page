Tabs

Accessible tabbed interface. Arrow keys navigate tabs; Home/End jump. Works with mouse, keyboard, and touch.

Overview

This tabbed interface follows the WAI-ARIA authoring practices for the tabs pattern. Each tab is a button with proper ARIA roles, and panels are linked via aria-controls and aria-labelledby.

Use the arrow keys to move between tabs, Home to jump to the first tab, and End to jump to the last tab. Panels are focusable and announced by screen readers.

Features

  • Full keyboard support (arrows, Home, End, and optionally Up/Down).
  • Touch-friendly tab spacing for mobile.
  • Live region announces the active tab change.
  • Responsive: tabs wrap and remain usable on narrow screens.
